# glp1-trial-watch-3

Tracking watchlist for the endocrinology group's **quarterly pipeline review**. This repo captures a durable record of currently recruiting GLP-1 receptor agonist trials in adults with type 2 diabetes — focusing on the late-stage (Phase 3) landscape ranked by planned enrollment — so the team can find the late-stage GLP-1 RA trials in T2D on GitHub rather than keeping them in notes.

## Contents
- **Parent summary issue:** track the recruiting-study search and its aggregate breakdowns (by phase and by sponsor class) and the headline selected trials.
- **Per-trial tracking issues:** one issue per selected Phase 3 trial — NCT ID, sponsor, phase, planned enrollment, and primary completion date.
- **Aggregate breakdown comment** on the parent issue (counts as returned by the registry analysis of the recruiting search).
